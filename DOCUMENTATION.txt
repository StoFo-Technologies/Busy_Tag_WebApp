PROJECT OVERVIEW
================================================================================
Status Tag is a premium Windows desktop application built with 
Electron that allows you to cleanly control your hardware display 
via a background USB serial connection.

The app dynamically processes GIF animations and beams them to your 
Status hardware. It features a state-of-the-art dark mode interface 
with ambient glassmorphism and runs seamlessly in the background (System Tray).

KEY FEATURES:
- Media Library: Processes the bundled designs categorized in subfolders (e.g. /cartoons, /gifs) within the embedded /designs folder (supports .gif, .png, .jpg, .webp).
- Priority Sorting: Puts "Available" and "Busy" at the top, with others sorted alphabetically.
- Automatic Sync: Instant detection of your Status device via USB.
- Boot Logo: The StoFo Logo automatically displays upon device connection.
- Auto-Revert Timers: Set active status to expire after 15m/30m/45m/1h.
- Brightness Control: Command the hardware screen brightness directly from UI.
- Background System Tray: Right-click quick toggles from your Windows taskbar.
- Real-time Notifications: Desktop alerts for connection status and actions.

================================================================================
HOW TO RUN THE APP
================================================================================

STEP 1: Install Dependencies
  Open PowerShell in the project directory and run:
  
  npm install
  
STEP 2: Start the Application
  npm start
  
  The dashboard window will open.
  
STEP 3: Connect Hardware Module
  - Connect your device via USB cable.
  - The app will detect it automatically and update the "Connection" badge.
  
STEP 4: Select a Status
  Click any animation card to send it to your device.

PROJECT STRUCTURE
================================================================================

main/
  ├─ main.js          → Main Electron process (Tray, IPC, GIF scanning)
  └─ preload.js       → Secure API bridge

renderer/
  ├─ index.html       → App layout and sidebar
  ├─ renderer.js      → UI logic and card generation
  └─ styles.css       → Premium glassmorphism design system

services/
  └─ serialService.js → USB communications and real-time frame processing

designs/              → Your bundled media asset library (organized into /cartoons and /gifs).

package.json          → Project configuration and scripts

================================================================================
TROUBLESHOOTING
================================================================================

Device not detected:
  → Ensure the USB cable is data-capable.
  → Verify Windows Device Manager shows a COM port for the device.
  
Hardware Screen is Dark:
  → Check the Brightness slider in the left sidebar.
