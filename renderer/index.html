Status Tag Help

How to use

1. Connect your Status Tag via USB cable.

2. Select any design from the dashboard to send it directly to your tag.

3. Use the Auto-Revert timer to automatically switch back to "Available" after a set duration.

4. Use the RESET DISPLAY button in the left sidebar to quickly clear the screen and interrupt any stuck animations.

Troubleshooting

Not connecting? Try a different USB cable (must support data transfer) or reconnect the device.
